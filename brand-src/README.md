## 三、只读约定

- 本目录**只读留档**：不参与页面渲染，不被 `site.css` 或任何 `.html` 引用。
- 页面用的图一律由 `python tools/make_images.py` 从本目录**派生**到 `assets/img/`；
  改尺寸/改格式只改生成参数，**不改这里**。
- 重新入库（换源图）时必须同步更新上表的字节数与 sha256。

## 五、已知限制

- **吉祥物分辨率偏低**：女孩仅 222px 宽。3 倍屏手机上按 160 CSS px 显示需要 480
  设备像素，会偏软。已在页面上限死 ≤160 CSS px 缓解；根治要**向中心索要高清源图**
  （≥1000px 的 PNG，或 PSD/AI）——对应计划书 **A14**。
- **会徽无矢量源**：现只有位图，favicon 在 16px 下的质量受限。对应计划书 **A15**。
- 会徽源图的四角为全透明。生成管线会先把透明像素的 RGB"外扩"为品牌蓝 `#2E5EA3`
  再缩放，以防第三方工具（在线 favicon 生成器、canvas、导出 JPEG 等）把透明区
  拍平成黑边（计划书摘要修正 3 / 决策 D8）。
